# Language Epithets — the 10-entry table

_2026-07-17 · tier: **draft — owner voice pass required** · fulfils the deferred authoring item
in `docs/plans/story-presentation-decisions.md` #6 (per-player beat conditioning): beats name the
bout-winning fighter as "<Name> the <Epithet>". One epithet per seed language, authored once,
used everywhere. Register: the book's — warm, plain, a little mythic; never tech-jargon._

| Language | Epithet | Why (the language's soul, made kid-legible) |
|---|---|---|
| Rust | **the Unrusting** | In a valley of corroding machines, the one who never corrodes. Memory-safe = nothing rots inside. |
| JavaScript | **the Somehow** | It shouldn't work. It works. Nobody knows. Runs anywhere, improvises everything. |
| TypeScript | **the Armoured** | The Somehow's sibling who went and got fitted for plate. Types are armour over the same wild heart. |
| Python | **the Plain-Spoken** | Says exactly what it means, and everyone understands. Beloved of beginners; underestimated in a scrap. |
| C++ | **the Many-Bladed** | Carries every weapon ever forged, including the ones that cut the wielder. Old power, sharp edges. |
| C | **the Bare-Handed** | The first fighter. No gloves, no guard-rails, nothing between fist and metal. Ancient and dangerous. |
| CSS | **the Cascade** | Fights like falling water — style on style on style, and the last one lands. Best-dressed in the league. |
| Go | **the Thousand-Handed** | Simple face, and then suddenly the punches arrive all at once, from everywhere. |
| Haskell | **the Spotless** | Never leaves a mess. No side effects, no wasted motion — the bout ends and the ring looks untouched. |
| Lua | **the Little Moon** | Small, bright, fits in any pocket of the sky. The littlest fighter, welcome everywhere. |

## Usage examples (beat-insert grammar)

- "…and when the dust settled it was **Pekoe the Plain-Spoken** still standing."
- "**Kiln Widow the Many-Bladed** paid the forfeit, true and paid in full."
- "The crowd had no name for it, so they used hers: **Sprocket the Somehow**."

## Rules

- Epithet keys off the fighter's **primary** language (first of the two seeds).
- Avoided on purpose: anything colliding with Gobblestone canon ("dreaming" is the goblins'
  word — Haskell therefore reads Spotless, not Dreaming).
- Owner voice pass may rename freely; keep one epithet per language and keep them
  fight-bill-shoutable.
